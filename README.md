# Northlight SEO for Grok Bot and Cursor

SEO made simple.

Northlight SEO gives your agent real SEO data and guided workflows, so its advice is grounded in your website instead of generic recommendations.

## What you can do

- Find and evaluate keywords
- Research competitors and content gaps
- Audit a website and prioritize fixes
- Analyze backlinks and find link prospects
- Track organic and Google Maps rankings
- Work with Google Search Console and Analytics data
- Research AI prompts and track brand mentions, citations, and competitors

The plugin includes twelve skills that guide your agent through complete SEO workflows, plus the hosted Northlight SEO MCP server for live data and project management.

## Connect

Install Northlight SEO from the Grok Bot or Cursor marketplace. The first time your agent uses a Northlight SEO tool, follow the OAuth prompt to sign in and approve the connection. There is no API key to configure.

To check the connection without using credits, ask: "Use Northlight SEO to check my connection and list my projects."

You need a Northlight SEO account. The plugin package is free. Hosted Northlight SEO plans and usage credits are described at [seo.northlight.ai/pricing](https://seo.northlight.ai/pricing).
